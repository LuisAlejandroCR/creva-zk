## Una frase que hay que cambiar si se regraba

La tercera línea dice **«Prior-work declaration first»**. El reglamento final del hackathon
cambió: ya no se admiten entregas que incluyan trabajo previo. Esta entrega **no lo incluye** —
ni una línea de Creva está aquí— pero la etiqueta hablada invita a la lectura equivocada en el
segundo diez. El sustituto, misma duración:

> Creva ZK. Everything in this repository was built this weekend. Creva, the platform, already
> existed — but this repository contains none of its code.
